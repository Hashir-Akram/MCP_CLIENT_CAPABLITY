# Module 3, Part 2 - Version B: Resources in Simple Words

Every way to define a resource: 16 ways in 3 families (write a function, ready-made box, add/combine/hide).

| File | Purpose |
|------|---------|
| MCP_Resources_B_Simple_Guide.docx | Plain-language guide (17 pages) |
| MCP_Resources_B_Simple_Slides.pptx | 13 picture slides |
| demo/01_all_resource_types_server.py | One server with all 16 ways |
| demo/02_all_resource_types_client.py | Runs each way, prints results |

## Run
    python -m venv venv && source venv/bin/activate
    pip install -r demo/requirements.txt
    cd demo && python 02_all_resource_types_client.py

Tested: Python 3.12, fastmcp 4.0.11, mcp 2.3.0.
